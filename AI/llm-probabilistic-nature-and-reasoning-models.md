# LLM은 다음 토큰을 맞히는 확률 모델이지만 추론 시간 계산량과 PRM으로 사고력을 획득했다

## 🤔 헷갈렸던 점
- 단순 통계적 단어 예측기에 불과한 LLM이 어떻게 인간 수준의 복잡한 논리 추론과 코딩 능력을 보여주는지 그 메커니즘이 모호했다.
- 최신 사고 모델(GPT-5.6 Sol, Claude Fable 등)이 기존 모델과 정확히 무엇이 다른지, 왜 답변 전 '생각 시간'을 가지면서 성능이 비약적으로 상승하는지 와닿지 않았다.
- OpenAI, Anthropic, Google의 대표 모델들이 보여주는 성향 차이가 단순한 체급 차이인지 사후 학습(Post-Training) 철학의 차이인지 명확하지 않았다.

## ✅ 정리
- **LLM의 근본적 본질: 확률 기반 언어 모델**:
  - LLM의 수학적 본질은 이전까지의 텍스트 문맥을 바탕으로 **다음에 올 가장 확률이 높은 토큰을 예측하는 통계 모델**이다.
  $$\mathbb{P}(w_t \mid w_1, w_2, \dots, w_{t-1})$$
- **'확률 예측기'가 '지능/사고'를 모방하게 된 3가지 요인**:
  1. **고차원 압축을 통한 세계 모델(World Model)의 형성**: 방대한 텍스트의 다음 단어를 맞히기 위해 내부 신경망 속에 논리 체계, 인과 관계, 물리학적 개념, 코드 실행 흐름을 고차원으로 압축하여 학습.
  2. **생각의 연쇄 (Chain of Thought, CoT)**: 중간 추론 토큰(`<thinking>`, 논리 전개)을 순차적으로 생성함으로써 스스로가 방금 쓴 문장을 다음 추론의 힌트로 활용.
  3. **에이전트 외곽 루프 (Agentic Loop & Tool Use)**: 텍스트 생성기 외부에 파일 탐색, 코드 실행, 웹 검색 등 도구 환경을 결합하여 자율 목표 달성 루프로 확장.
- **최신 사고 모델(Reasoning Models)의 2가지 핵심 기술적 동인**:
  1. **추론 시간 계산량 (Inference-Time Compute / Test-Time Search)**:
     - 질문 수신 즉시 첫 단어를 뱉는 방식(Think as you speak)에서 탈피.
     - 최종 출력 전 **배경에서 수백~수천 개의 숨겨진 생각 토큰(Hidden Thinking Tokens)**을 쏟아부으며 수만 가지 논리 경로를 심층 탐색/자가 검증.
  2. **과정 중심 보상 모델 (Process Reward Model, PRM)**:
     - 최종 정답 여부만 평가하던 기존 RLHF를 넘어, **중간 논리 단계(Step-by-Step) 하나하나의 타당성과 정밀함에 보상**을 부여하는 강화학습(RL) 적용.
- **상용 주요 AI 모델별 사후 학습(Post-Training) 성향 비교**:
  - **OpenAI (GPT / Sol 계열)**: 코드 샌드박스 실행 궤적 및 수학 증명 엔진 결합 RL $\rightarrow$ 결정론적 논리 추론과 실행 기반 에러 교정에 극도로 강력.
  - **Anthropic (Claude / Fable 계열)**: Constitutional AI 및 메타인지/적대적 자기 비판 데이터 $\rightarrow$ **"내가 틀렸을 가능성"을 스스로 의심하는 자아비판**, 보안/아키텍처/Edge Case 탐색에 뛰어남.
  - **Google (Gemini / Pro 계열)**: Native Multimodal 구조 및 초거대 롱 콘텍스트(Long Context) $\rightarrow$ 수백만 토큰 문맥을 통째로 분석하며 시각/코드/텍스트 간 원인 격리에 강점.

### 💡 핵심 비교: 전통적 LLM vs 최신 추론 모델 패러다임
```
[전통적 LLM]
사용자 입력 ──▶ [즉시 토큰 생성 (Think as you speak)] ──▶ 답변 출력
(직관적/1차원적 반응, 중간 논리 탈락 시 복구 불가)

[최신 사고 모델 (Reasoning Models)]
사용자 입력 ──▶ [Test-Time Compute: 숨겨진 CoT + PRM 검증 + 논리 탐색] ──▶ 정제된 답변 출력
(심층적 다차원 탐색, 자체 오개념 교정 후 최종 응답)
```

상용 LLM 간의 차이는 결국 **"답변 전 배경에서 고민하도록 만든 강화학습 알고리즘(Inference-Time Compute)"**과 **"각 사가 사후 학습 과정에서 부여한 철학 및 데이터의 차이"**에서 비롯된다.
