# Python의 and / or은 논리 판단이 아니라 값 선택 연산자

## 🤔 헷갈렸던 점
- `and`, `or`는 논리 연산자이므로 항상 `True` / `False`를 반환한다고 생각했다.
- C, Java 같은 언어에서의 논리 연산자 개념을 그대로 Python에 적용했다.
- 조건식이 아닌 곳에서 `or`를 사용하는 이유가 잘 이해되지 않았다.

## ✅ 정리
- Python에서 `and`, `or`는 **논리 판단의 결과를 반환하는 연산자라기보다**
  **피연산자 중 하나의 값을 그대로 반환하는 연산자**에 가깝다.
- 동작 방식은 다음과 같다.
  - `A or B`  
    → A가 truthy이면 A를 반환, 그렇지 않으면 B를 반환
  - `A and B`  
    → A가 falsy이면 A를 반환, 그렇지 않으면 B를 반환
- 따라서 결과는 `True` / `False`가 아니라 **실제 값(value)** 이 될 수 있다.

### 💡 실사용 예시: 조건문 없이 기본값 처리
```py
user_name = input_name or "guest"
````

* `input_name`이 존재(truthy)하면 해당 값이 할당된다.
* `input_name`이 비어있거나(None, "", False 등) falsy이면 `"guest"`가 할당된다.
* 불필요한 `if` 문 없이 간결하게 기본값을 처리할 수 있다.

Python의 `and / or`는 **조건 분기보다 값 선택을 위한 표현식**으로 이해하는 것이 더 정확하다.
